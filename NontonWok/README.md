# NontonWok Provider

This provider allows accessing movies and series from NontonWok (nonton.work) using Cloudstream.

## Features

- Browse movies, TV series, and animation
- Search for content
- Get detailed information about movies and series
- Stream videos

## Usage

1. Add the provider to your Cloudstream instance
2. Sync the repository
3. Enable the NontonWok provider

## Notes

- This provider is still in development and may not be fully functional
- It supports Indonesian content (lang = "id")
- Currently supports Movie and TvSeries types
